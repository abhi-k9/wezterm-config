Check the APP / WEZ badge first. Fullscreen, the mode toggle, and host-clipboard paste are always reserved. Key tables, workflow steps, and architecture concepts have separate sheets.

Always on — fullscreen, toggle, and paste

Alt+EnterToggle WezTerm fullscreen in APP and WEZ.
Ctrl+Shift+F12Toggle the current GUI window between APP and WEZ.
Ctrl+Shift+vPaste the host clipboard into the focused terminal, including a Zellij pane; macOS Cmd+v also works.
F12Forwarded for Zellij’s Normal/Locked toggle; does not change WezTerm mode.
EscSent onward immediately. No Escape leader or double-press workaround.

APP reserves fullscreen, the toggle, and paste. Plain Ctrl+v remains an application key. WEZ adds the controls below. On compact Mac keyboards F12 may require Fn. OS shortcuts and native menu actions remain OS-controlled. Zellij’s F12 lock requires its own binding.

WEZ only — clipboard, view, and reload

Ctrl+Shift+cCopy the outer-terminal selection to the host clipboard; macOS Cmd+c. Paste is always available above.
Ctrl+Shift+fOuter-terminal search; macOS Cmd+f.
Ctrl+Shift+pCommand palette; macOS Cmd+Shift+p.
Ctrl+Shift+= / - / 0Font size increase / decrease / reset; macOS Cmd+= / - / 0.
Ctrl+Shift+rReload; macOS Cmd+r. Reload resets input modes to APP.
Ctrl+Shift+lDebug overlay.

These keyboard actions are not reserved in APP. WezTerm’s own copy/search/picker UI temporarily handles its UI keys; toggling APP closes copy/search.

WEZ only — outer tabs and windows

Ctrl+Shift+tNew outer tab; macOS Cmd+t.
Ctrl+Shift+nNew native window; macOS Cmd+n. The new window starts APP.
Ctrl+Tab / Ctrl+Shift+TabNext / previous outer tab.
Ctrl+Shift+1…8Outer tabs 1–8; macOS Cmd+1…8.
Ctrl+Shift+9Last outer tab; macOS Cmd+9.

The tab bar displays zero-based indices. The prefix number commands below use those indices; direct numeric shortcuts retain the first-eight/last-tab convention. Direct number/font chords use physical number-row and +/- positions to handle Shift correctly. These are not Zellij tabs.

WEZ only — one-shot command prefix

Press Ctrl+Shift+Space, release, then one key below. The badge shows WEZ · CMD. One action or a two-second timeout returns to WEZ.

cNew outer tab in CurrentPaneDomain.
xClose outer pane, requesting confirmation.
b / nPrevious / next outer tab.
0…9Activate zero-based outer tab index.
Shift+| / -Split side by side / above and below.
h / j / k / lFocus left / down / up / right.
← / ↓ / ↑ / →Resize focused outer pane by five cells.
f / zPane picker / zoom toggle.
p / wLauncher (profiles/tabs/workspaces) / outer workspace selector.
s / [Outer search / copy mode.
r / Shift+?Reload / command palette.

This prefix is not bound in APP. An unknown key cancels the prefix and follows WEZ routing. Escape cancels it and sends one Escape onward. F12 also passes through a pending prefix.

Scroll the correct layer

Zellij NormalCtrl+s enters Scroll mode; unlock with F12 first when Locked.
Zellij ScrollCtrl+b / Ctrl+f or PageUp/PageDown: pages. u / d: half-pages.
Zellij ScrollCtrl+c: bottom and Normal; Escape/Enter: Normal.
WEZ onlyShift+PageUp / Shift+PageDown: outer history. Mac compact: Shift+Fn+↑ / ↓.
WezTerm copy modeCtrl+b / Ctrl+f: pages; Ctrl+u / Ctrl+d: half-pages; g / Shift+g: oldest/newest retained output.

Zellij owns each inner pane’s history. The right-edge WezTerm bar represents the active outer pane. Full-screen editors have their own navigation. See the scroll workflow.

WezTerm copy/search UI

Enter copy modeIn WEZ: Ctrl+Shift+Space, then [.
h / j / k / lMove the selection cursor; arrows also work.
v / Shift+vCharacter / line selection; Ctrl+v selects a block.
y / qCopy and close / close without copying.
Search matchesCtrl+n / Ctrl+p: next/previous; Ctrl+r: matching mode.
Return to APPCtrl+Shift+F12 closes this copy/search UI and clears outer command tables.

For Neovim or an inner Zellij pane, prefer that layer’s selection/copy operation. Outer copy mode selects the rendered terminal, not an editor’s buffer.

Zellij and Neovim keep their own keys

F12Zellij Normal ↔ Locked in the companion config.
Zellij NormalCtrl+p: Pane; Ctrl+t: Tab; Ctrl+s: Scroll.
Zellij LockedOrdinary application shortcuts reach Neovim; F12 unlocks Zellij.
Neovim editingEsc leaves insert mode normally; no double Escape.

These Zellij entries reflect the companion config and retained v0.45.1 defaults. This repository does not configure those applications. Read the full input-routing guide for OS/encoding boundaries and clipboard setup.

Close the intended layer

NeovimUse its save/quit commands, such as :wq or :q.
Inner Zellij paneZellij Normal: Ctrl+p, then x.
Inner Zellij tabZellij Normal: Ctrl+t, then x.
Detach ZellijZellij Normal: Ctrl+o, then d.
Outer WezTerm paneWEZ: Ctrl+Shift+Space, then x.
Outer WezTerm tabWEZ: Ctrl+Shift+W; macOS Cmd+W.
Native windowOS close button; Alt+F4 on Windows. This affects all outer tabs.

Outer closes affect the entire Zellij client hosted there, not one inner pane. Save work and detach explicitly when preserving the Zellij session is intended. Safe/idle outer processes may skip confirmation. See lifetime.
