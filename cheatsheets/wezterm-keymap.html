Look up an action here. Leader means press Escape, release, then press the next key. For task sequences use workflows; for pane/tab/window relationships use architecture.

Start here — the leader key

one action per prefix · 2-second timeout

Esc → key activates a terminal action. For example, Esc then c opens a tab. The wave in the tab bar indicates that the leader is active.

Escape changes application input. A single Esc is consumed; timeout does not send it to the app. Press Esc Esc to send one Escape. Unbound keys after the leader are also consumed.

Hold modifiers shown with + together; arrows → between keycaps mean a sequence. “Leader + key” below always means a sequence, not holding Escape.

If that interrupts your editor, use the complete Ctrl+a alternative in the installed copy of wezterm.local.lua. It updates the leader and its double-press forwarding shortcut together.

Close a pane, tab, or window

PaneEsc → x — close the focused pane (CloseCurrentPane, shared binding).
TabCtrl+Shift+W on Windows/Linux; Cmd+W on macOS — close the current tab and all its panes (CloseCurrentTab, built-in).
WindowUse the native title-bar close button. Alt+F4 is the Windows window-close shortcut and is common on Linux window managers. On macOS use the red close button. These target the window, including all its tabs.

Pane/tab actions request confirmation with confirm = true; native window closing uses window_close_confirmation = 'AlwaysPrompt'. A prompt can still be skipped for idle shells or other processes WezTerm considers safe. There is no custom window-close binding in this config.

Closing the last pane also removes its tab; closing the last tab also removes its window. See architecture: close scope and lifetime and the closing workflow.

Panes — split, focus, resize

leader first
Leader Shift+|Split side by side; type the | symbol with Shift held.
Leader -Split into an upper and lower pane.
Leader h / lFocus left / right.
Leader j / kFocus down / up.
Leader ← ↓ ↑ →Adjust the focused pane in that direction by 5 cells.
Leader fShow pane labels; select one to focus.
Leader zZoom the current pane; repeat to restore the split view.
Leader xClose the focused pane; requests confirmation. Closing the last pane also closes its tab.
Each resize needs a fresh leader. “Horizontal split” in WezTerm means side by side; “vertical split” means upper/lower.

Tabs & windows

zero-based tabs
Leader cNew tab in the current pane's domain.
Leader b / nPrevious / next tab.
Leader 0 … 9Activate tab index 0–9. Index 0 is the first tab; index 1 is the second.
Ctrl+TabNext tab (built-in).
Ctrl+Shift+TabPrevious tab (built-in).
Ctrl+Shift+nNew window (built-in; Cmd+n on macOS).
Built-in number shortcuts keep their own convention: Ctrl+Shift+1 selects the first tab, while Leader 1 selects the second. The tab bar is always visible at the bottom.

Clipboard & search

system clipboard
Ctrl+Shift+cCopy the selected text.
Ctrl+Shift+vPaste clipboard contents into the focused application.
Leader sSearch scrollback; selected text seeds the query.
Ctrl+Shift+fOpen the same search without the leader.
Ctrl+n / Ctrl+pNext / previous match while the search UI is open.
Ctrl+rCycle the search matching mode while searching.
On macOS, built-in Cmd+c, Cmd+v, and Cmd+f remain available. A terminal application that captures mouse input may require holding Shift to select terminal text.

Copy mode — keyboard selection

built-in mode keys
Leader [Enter copy mode; subsequent keys work inside this mode.
h j k l / arrowsMove left, down, up, right.
v / Shift+vStart a character / whole-line selection.
Ctrl+vStart a rectangular block selection.
g / Shift+gGo to the top / bottom of scrollback.
PageUp / PageDownMove through output one page at a time.
yCopy the selection and leave copy mode.
qLeave copy mode without copying.
These are copy-mode bindings, not shell commands. Copy mode is useful when mouse selection is awkward or you want an exact line/block selection.

Everyday controls

no leader
Ctrl+Shift+=Increase font size (the + key on a US keyboard).
Ctrl+Shift+-Decrease font size.
Ctrl+Shift+0Reset font size to the configured value.
Ctrl+Shift+rReload configuration now; automatic reload also watches saved edits.
Alt+EnterToggle fullscreen (built-in; OS shortcuts can take precedence).
The Ctrl+Shift shortcuts are explicitly configured across platforms. macOS built-in Cmd shortcuts remain enabled. Font-size shortcuts change the current window; edit font_size for the persistent default.
