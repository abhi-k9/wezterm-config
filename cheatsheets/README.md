# WezTerm cheatsheets

Open the HTML files in a browser. Each uses Catppuccin Macchiato, works offline,
and has a light print layout.

- [Keymap](wezterm-keymap.html): shortcut lookup, including pane/tab/window close actions.
- [Workflows](wezterm-workflows.html): task sequences for daily terminal work.
- [Architecture](wezterm-architecture.html): concepts, relationships, and lifetime.

[Overview](wezterm-cheatsheet.html) preserves the previous combined-sheet URL.
Keep the files together so the companion navigation links work locally.
