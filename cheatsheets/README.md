# WezTerm cheatsheets

Open the HTML files in a browser. Each uses Catppuccin Macchiato, works offline,
and has a light print layout.

- [Keymap](wezterm-keymap.html): APP/WEZ routing, outer shortcuts, and inner/outer close and scroll actions.
- [Workflows](wezterm-workflows.html): daily WezTerm → Zellij → Neovim task sequences.
- [Architecture](wezterm-architecture.html): layers, independent modes, relationships, and lifetime.

The [input-routing guide](../docs/INPUT.md) documents the complete mode contract,
migration from the Escape leader, local customization, and platform verification.

[Overview](wezterm-cheatsheet.html) preserves the previous combined-sheet URL.
Keep the files together so the companion navigation links work locally.
