Overview Keymap Workflows Architecture

Daily work starts in APP. Temporarily choose WEZ for outer controls, then return APP. Full shortcut tables are in keymap; relationships are in architecture.

Daily editing: APP → Zellij → Neovim

  1. Leave WezTerm in APP and start Zellij with your usual launcher.
  2. Open Neovim in an inner pane. Use F12 until Zellij indicates Locked when its ordinary bindings should reach the editor.
  3. Use Escape normally. Alt+Enter still controls fullscreen without changing Zellij’s lock state.
  4. Unlock Zellij with F12 for pane/tab/session commands. WezTerm stays APP.

APP and Zellij Locked are independent. The outer mode toggle is Ctrl+Shift+F12; plain F12 belongs to Zellij.

Temporarily use outer controls

  1. Toggle Ctrl+Shift+F12 and check for WEZ in the outer tab bar.
  2. Use fonts/copy directly, or press Ctrl+Shift+Space, release, then p for the launcher, c for an outer tab, or another prefix command.
  3. Return to APP with the same mode toggle. Pending command tables and copy/search UI are released.
  4. Keep Zellij’s lock state as needed; switching WezTerm mode never sends it a plain F12.

The mode covers all outer tabs/panes in this GUI window. Another native window has an independent mode and starts APP.

Scroll an inner Zellij pane quickly

  1. Focus the inner pane that produced the shell/build output. In APP, unlock Zellij with F12 if its status says Locked.
  2. Press Ctrl+s for Zellij Scroll mode. Ctrl+b / Ctrl+f or PageUp/PageDown move by a page; u / d move by half-pages.
  3. Press Ctrl+c to return to the bottom and Zellij Normal. Escape/Enter also leave Scroll mode.
  4. Re-lock Zellij with F12 before returning to editor shortcuts if desired.

For a shell directly in WezTerm, enter WEZ for Shift+PageUp/PageDown or prefix [. Mac compact page keys are Fn+↑/↓; add Shift for outer paging. The outer scrollbar is not an inner-pane history selector. Scrolling key reference.

Copy and paste at the right layer

  1. For inner text, use Neovim’s configured clipboard provider or Zellij’s copy operation. OSC52 can deliver clipboard writes to the host with a suitable setup.
  2. Paste from the host clipboard with Ctrl+Shift+v in APP or WEZ; Cmd+v also works on macOS. Focus the intended Zellij pane and enter Neovim Insert mode first when pasting into an editor buffer.
  3. For an outer-terminal selection, copy in WEZ with Ctrl+Shift+c / Cmd+c. Prefix [ offers keyboard selection of outer history.
  4. If you entered WEZ to copy, return APP. Test clipboard behavior with non-sensitive text along any SSH/WSL path you use.

Plain Ctrl+v keeps its application behavior; the paste shortcut is Ctrl+Shift+v. This config does not configure Neovim’s clipboard provider. A WezTerm selection covers the rendered outer terminal; use the editor for a semantic buffer selection.

Arrange editor, shell, and logs in Zellij

  1. In APP, unlock Zellij if it is Locked.
  2. Use Zellij Pane mode (Ctrl+p), then r for a right split or d for a lower split. Run the editor, build shell, and log viewer in the intended inner panes.
  3. Use Zellij’s focus/resize controls, and F12 Locked for Neovim’s own editor splits and mappings.
  4. Use WEZ outer splits only when an additional outer session is useful; its prefix | / - creates those separate outer terminals.

A Neovim editor split, Zellij pane, and WezTerm pane belong to different layers. See the hierarchy.

Finish work and close the intended scope

  1. Save editor changes. Neovim :wq saves/quits an editor window; :q may return to a parent shell and refuses unsaved changes.
  2. For an inner pane or tab, unlock Zellij and use Ctrl+p then x (pane) or Ctrl+t then x (tab).
  3. To preserve a Zellij session before leaving its outer terminal, use Zellij Normal, Ctrl+o then d to detach explicitly.
  4. For an outer close, enter WEZ: prefix x closes an outer pane, Ctrl+Shift+W / Cmd+W closes an outer tab. A native close button/Alt+F4 affects the window.
  5. Respond to any outer confirmation. A stateless/idle process may be exempt.

Closing the outer client may detach or end the Zellij session according to its on_force_close policy. The companion shared config uses detach; confirm the policy in the setup actually running. See close actions and lifetime.

Use a machine-only launch profile

  1. Keep private commands in the installed home-directory wezterm.local.lua beside the active .wezterm.lua.
  2. Guard machine-only menu entries by platform/tool availability. The tracked local file stays a commented public example.
  3. After an edit, enter WEZ and reload with Ctrl+Shift+r / Cmd+r. The badge returns APP.
  4. Enter WEZ, prefix p, and choose the launch entry. Return APP for normal terminal use.

A missing local file is allowed. Legacy leader/default-key overrides are rejected; launch-menu-only overrides remain compatible.

Separate inner sessions and outer projects

  1. Use Zellij’s own tabs/sessions to organize work inside a client; name sessions with the launcher you normally use.
  2. For outer WezTerm workspace grouping, enter WEZ and use prefix w. The create entry assigns a name automatically.
  3. From a pane in that outer workspace, wezterm cli rename-workspace project gives it a meaningful name.
  4. Re-enter APP for work. An outer workspace is not a saved Zellij/Neovim application state.

Upgrade or reload without restoring the old key trap

  1. Follow the copy-based update instructions; pulling Git alone does not update the active home-directory file.
  2. Keep private launch profiles. Remove enabled legacy config.leader or default-binding overrides; put extra terminal shortcuts in config.key_tables.wezterm.
  3. For the first upgrade, reload using the current old map. Afterwards toggle WEZ before Ctrl+Shift+r / Cmd+r.
  4. Expect APP after reload. Check one Escape in Neovim, F12 in Zellij, fullscreen, and the independent window toggle.

Reloading settings does not restart running programs. See the migration checklist and platform verification.
